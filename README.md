# AStar
A* Pathfinding Starter Project (Unity)

A Teaching-Oriented Implementation for Game AI Education

This repository contains a clean, beginner-friendly Unity implementation of the A* pathfinding algorithm, designed as the instructional project for a game AI teaching module. It supports the core requirements of the take-home final: presenting an AI concept, providing an implementation, and enabling hands-on learning.

⸻

## 🎯 Project Overview

This starter project demonstrates how modern games use navigation and pathfinding to guide agents intelligently through an environment. Students can interact with a functioning A* system, analyze its components, and extend it with new behaviors.

The project includes:
	•	A grid-based world representation
	•	A full A* pathfinding implementation
	•	A visual debug overlay (grid gizmos + path line)
	•	A click-to-move agent that follows computed paths
	•	Obstacle handling using collision detection

This repository is intentionally minimal and clean so learners can focus on understanding the AI technique.

⸻

## 🧠 What Students Will Learn
	•	How a grid represents navigable space in games
	•	How A* prioritizes nodes using G, H, and F cost
	•	How to get neighbors, avoid obstacles, and reconstruct paths
	•	How Unity components communicate to form an AI system
	•	How to extend A* with additional game mechanics

This project is designed for teaching purposes and pairs with a tutorial and video demonstration.

## ▶️ How to Run
	1.	Clone or download this repository.
	2.	Open Unity 2022 LTS or later (or your project’s target version).
	3.	Load AStarScene.unity.
	4.	Press Play.
	5.	Right-click anywhere on the ground to move the agent.
	6.	Observe:
	•	Path calculations in the Console (for debugging)
	•	Grid gizmos in Scene view
	•	Real-time path visualization in Game view

## 🧩 How It Works (High-Level Summary)

1. GridManager
	•	Converts world positions ↔ grid coordinates
	•	Generates nodes with walkability flags
	•	Provides neighbor lookup

2. GridNode

Represents one tile in the grid.
Holds:
	•	Walkable state
	•	Grid coordinates
	•	World position
	•	G, H, F costs
	•	Parent reference

3. AStarPathfinder

Implements:
	•	Open/closed sets
	•	Cost updates
	•	Heuristic evaluation
	•	Path reconstruction

4. AgentMover
	•	Detects mouse clicks
	•	Requests a new path
	•	Moves the agent along nodes

5. PathVisualizer
	•	Uses a LineRenderer to visualize the calculated path

## 🧪 Suggested Student Exercises

These tasks are scaffolded from beginner → intermediate → advanced.

🟦 Beginner
	•	Allow diagonal movement
	•	Change grid resolution
	•	Change agent speed
	•	Add more obstacles

🟩 Intermediate
	•	Add weighted nodes (mud, water, slow zones)
	•	Visualize G, H, and F values on each tile
	•	Add runtime obstacle creation (click to place boxes)
	•	Add smooth turning or spline interpolation

🟥 Advanced
	•	Compare A* to Breadth-First Search
	•	Implement Jump Point Search optimization
	•	Replace grid with a navigation graph
	•	Add enemy AI that chases the player using A*

These exercises support the pedagogical goals of the assignment.
